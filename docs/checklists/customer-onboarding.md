# 客户上线 Checklist

> **配套**:`docs/checklists/first-deploy.md`(技术部署侧) / `docs/checklists/equal-protection-l3.md`(合规侧)
> **使用**:本表逐项勾选,任何未勾项 = 上线阻塞。

---

## 一、合同 / 商务

- [ ] 软件买断合同(源码 + 实施)签订
- [ ] 运维订阅合同签订 + 起止时间登记(admin_db 系统初始化时填)
- [ ] 客户对接人 / 法人 / 紧急联系人登记到 admin_db `customer_user_role`

## 二、客户环境就绪

- [ ] 云服务器到位(最低 4 核 / 8GB / 100GB SSD,带 ≥ 10 Mbps 公网带宽)
- [ ] 域名 ICP 备案 + 解析到服务器公网 IP(`api.<customer-domain>`)
- [ ] 域名 SSL 准备(Let's Encrypt 自动走 Caddy;若有自有证书,先导入)
- [ ] OSS / 对象存储桶(如客户自购阿里云 OSS 或 AWS S3,用于 OTA 固件包)
- [ ] 异地备份目标到位(OSS 桶 / 备用机,二选一)

## 三、第三方账户

- [ ] 微信小程序 AppID + AppSecret(每个客户一个独立小程序,见 `需求分析.md` § 11.1)
- [ ] 微信支付商户号 / API v3 密钥 / 平台证书(走**微信直连**或**汇付天下**,客户配置决定)
- [ ] (可选)短信网关 / 邮件服务(SMTP)配置 — 当前**只通过 Webhook**,客户按需自配
- [ ] (可选)监管平台对接 — 锂康码 / 一网统管数据上报国密 SM2/SM4 证书

## 四、白标 / 品牌配置

- [ ] Logo(高清 PNG / SVG)
- [ ] 应用名称(客户中文名 + 英文名)
- [ ] 主题色 / Icon / 字体(可继承 antd 默认,只覆盖主色)
- [ ] 客服联系电话(用于公示)
- [ ] 客服坐席微信(由客户运营配置;用于微信原生客服会话推送)
- [ ] 服务协议 / 隐私声明文本(系统默认模板可改)
- [ ] 首条公告(强制必填,客户首次扫码的引导)

## 五、计费 / 财务配置

- [ ] 计费规则模板创建(电费 + 服务费分别配置;**价费分离**底线,见 `需求分析.md` § 3.3)
- [ ] 分时电价模板(高峰 / 平段 / 低谷时段)
- [ ] 充值档位(最低 1 档,推荐 5 档,见 admin `pricing_template`)
- [ ] 优惠券发放规则(用户领取 / 自动规则触发)
- [ ] 会员卡模板(月卡 / 年卡,可选)
- [ ] 分账模板(参与方 ≤ 8,见 `split_template` + `split_party`)
- [ ] 分账模式:A 或 B(见 `需求分析.md` § 9.2)

## 六、设备 / 站点

- [ ] 站点信息录入(名称 / 地址 / 经纬度 / 服务类型)
- [ ] 设备型号与硬件厂关系(`device_meta.model` ↔ `gateway_db.vendor.vendor_code`)
- [ ] 适配器启用(每客户按需启用对应硬件厂 adapter;见 `gateway_db.vendor` + `技术规格.md` § 7.1)
- [ ] 设备注册(每台 device_id 录入 + 推送协议配置)

## 七、角色 / 权限

- [ ] 角色预置检查(7 个角色,见 admin_db.role;按需调整)
- [ ] 客户管理员账号创建(首个 PC 后台 root)
- [ ] 客服坐席配置(微信原生客服消息推送)
- [ ] 数据范围权限分配(按项目 / 区域 / 站点)
- [ ] 字段级脱敏规则(手机号 / 身份证 / 银行卡,见 `需求分析.md` § 11.2)

## 八、告警 / Webhook

- [ ] 客户告警订阅(PC 后台 + 小程序 + Webhook)
- [ ] Webhook 接收方 URL + HMAC 共享密钥
- [ ] 告警分级规则(低 / 中 / 高,见 `需求分析.md` § 10.2)
- [ ] T-7 证书过期告警 webhook 通道配通

## 九、灰度 / 测试

- [ ] 用 `dev-charging-test` 桩端模拟器 → 内网测试扫码 / 启动 / 结束全流程
- [ ] 小程序开发者工具导入 → 测试用 test_appid
- [ ] PC 后台登录跑通 → 配置一条站点 + 一台桩 + 完成一次订单
- [ ] 退款流程跑通(用微信直连 1 分钱测试单)
- [ ] (可选)对接监管平台测试一次上报

## 十、合规 / 法务

- [ ] 等保三级测评 — 走 `equal-protection-l3.md`
- [ ] 个人信息保护法 — 用户协议 / 隐私声明已备案
- [ ] 价费分离 — 计费规则审查(系统已强制,文档确认)
- [ ] 七重防护 — 设备厂商提供合规检测报告(本系统不背)

## 十一、培训 / 文档

- [ ] 客户运维培训完成(4 小时,讲部署 + 日常运营 + 应急 Runbook)
- [ ] 客户客服培训完成(2 小时,讲用户侧使用流程)
- [ ] 文档交付:`README + 需求分析 + 技术规格 + cross-reference + runbook/* + checklists/*`

## 十二、上线批准

- [ ] 客户方代表签署《系统验收确认书》
- [ ] 我们交付工程师签《交付完成确认书》
- [ ] 运维订阅起算日开始计费
