# 乐摇摇体验分支记录

记录日期为2026年9月30日。本文区分实际保存、界面交互与无法完成的分支，不能作为真实设备和支付结算的全链路验收报告。主方案见[乐摇摇体验与 ChargePilot 改造方案](leyaoyao-experience-and-redesign.md)。

## 状态定义

| 标记 | 含义 |
| --- | --- |
| 保存验证 | 提交并重新读取，确认持久化结果 |
| 交互验证 | 实际进入并操作界面，未验证生产订单或硬件结果 |
| 受限 | 空数据、无响应、缺少设备或需要另行完成的操作 |
| 未完成 | 发现入口但仍未完整执行成功分支 |
| 排除 | 用户要求不考虑脉冲 |

同一编辑器的不同选择都列出，不把重复截图数量当作分支数量。验证了公共保存流程，不代表每种计费组合都已保存和真实结算。

保障购买属于单独付费开通，未纳入已执行操作。非充电设备的类型分支也不能算作已完整体验。后续完成补测时应逐行更新本文状态，不能把界面查看升级为保存验证或硬件闭环。
