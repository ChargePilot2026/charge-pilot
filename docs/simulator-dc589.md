# DC589 模拟设备

依据 [厂商 5.8.9 协议](protocol/dc589.pdf)，通过真实 TCP 连接 `127.0.0.1:9100`。必须先在后台创建 DC589 TCP 厂商及设备；设备编号为 16 位十进制数字。模拟器不直接修改订单、钱包或数据库。

## 同时运行两个 TUI

在两个终端分别执行：

```powershell
go run ./cmd/simulator-dc589 -board-id 5348240514082652 -ports 2 -control 127.0.0.1:9190 -state-file .tmp/simulator-1.json
go run ./cmd/simulator-dc589 -board-id 5348240514082653 -ports 2 -control 127.0.0.1:9191 -state-file .tmp/simulator-2.json
```

默认开启 TUI。Tab 切换端口、参数、待确认上报、日志；上下键选择端口，M/Enter 打开操作菜单；Enter 打开表单并再次提交，Tab 切换字段，Ctrl+U 清空输入，Esc 取消，PgUp/PgDn 滚动，Q/Ctrl+C 退出。退出保留状态文件，重新打开继续会话；新建干净设备状态时换用新状态文件。不要让两个实例共用设备号、控制端口或状态文件。

运行时心跳固定采用：任一端口充电时 **15 秒**，全部端口空闲时 **60 秒**。登录、周期设置及充电状态切换时额外立即报告当前状态。网关通过 A6 同步该策略，读超时为当前周期的三倍（充电 45 秒、空闲 180 秒）；模拟器每秒推进计量，计量更新频率不等于心跳上报频率。

支持在线刷卡、移卡、余额查询、投币/离线卡/免费启动、负载功率、插入/拔出充电器、端口故障及恢复、温度、电压、烟雾、断网重连、重启、模拟升级、立即心跳、校时、旧固件参数请求、本地参数表编辑。卡持续贴住只产生一次刷卡，必须移开再刷；再次刷卡的加时由服务器处理。金额模式到价停止、累计时长上限等由平台下发停止，模拟器不代替服务端计费。

充电中可随时调整负载功率：上下键选择端口，按 **P**（或操作菜单的“调整负载功率”），输入 W 并按 Enter。表单显示当前功率，支持 0.1W 精度，范围 0～6553.5W。调整只影响所选端口，后续每秒计量和心跳使用新功率；已有累计电量保留。设为低功率或 0W 时，仍按设备参数执行满充或移除检测。

参数页显示设备身份、完整参数表、卡余额回执、移除功率参数及升级模块状态；本地参数编辑会影响设备读回结果，后台仍使用真实参数下发/读回指令。重启和升级会终止充电；断网保留正在充电的会话。

## 无界面和自动化控制

`-tui=false` 适合脚本/CI。HTTP 控制只允许绑定 loopback，`GET /state` 返回状态，`POST /events` 接收物理操作，操作与 TCP 命令在同一设备循环串行执行。例如：

```powershell
Invoke-RestMethod http://127.0.0.1:9190/events -Method Post -ContentType application/json -Body '{"type":"power","port":1,"power_deciwatts":2500}'
Invoke-RestMethod http://127.0.0.1:9190/events -Method Post -ContentType application/json -Body '{"type":"card","port":1,"card":100001}'
Invoke-RestMethod http://127.0.0.1:9190/events -Method Post -ContentType application/json -Body '{"type":"remove-card","port":1}'
```

物理事件类型与 TUI 菜单对应，字段见 `Input`。功率按 0.1W，卡号 uint32，温度摄氏度，电压伏特；本地启动 `consumer` 为 0投币/1离线卡/4免费，`quantity` 为分钟或0.01度。`config` 的 `config` 字段接收完整参数表。

## 指令覆盖

| 指令 | 模拟行为 |
| --- | --- |
| A0/A1 | 身份注册、服务器校时、注册拒绝与重试 |
| A2/A3 | 重启/升级；遵循协议成功不回 A3，断线后重新注册 |
| A4/A5 | 心跳、端口计量、20端口分帧、漏三次回执重连 |
| A6/A7 | 心跳周期及端口遥测开关 |
| A8/A9 | 请求校时与服务器时间应用 |
| B0/B1、B2/B3 | 全端口/仅状态/单端口查询，完整36字节详情 |
| B4/B5 | 本地充电事件与重试确认 |
| B6、BD、D0/D1 | 在线刷卡、拒绝、余额查询及回执 |
| B7/B8 | 时长/电量/平台及长充模式，失败码、重复订单幂等 |
| B9/BA、BB/BC | 停止、正确回执、结束计量、待确认报告重发 |
| C0/C1、C2 | 故障/恢复的状态、故障上报确认、分档切换 |
| C3/C4、C5/C6、C7 | 参数校验与拒绝码、完整读回、旧固件请求同步 |
| E0/E1 | 移除功率参数设置/查询，小端编码与失败标记 |
| F0..F5 | 主板与通信模块内部升级交换，状态与帧记录可见 |

电量按功率积分，时长按设备时钟递减，支持档位折扣、满充停止、拔除停止、过载/烟雾/高温。长充模式跳过满充与拔除检查。网络重连保留参数、端口、订单计量和待确认报告；状态文件跨进程保存这些内容及已完成订单防重放记录。

F0..F5 是主板与模块内部串口协议，不发给运营网关。PDF 未定义固件二进制下载协议，因此模拟器模拟内部交换与版本升级，不能据此宣称验证了真实厂商升级包传输或烧录。C3 的6..8档扩展仅用于特殊2路8档主板，当前模拟所选通用DC589五档模型。
